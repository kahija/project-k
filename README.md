# Project K

Portfolio personnel de Kahina, développeuse front-end React.

Le projet présente une interface immersive en dark/light mode, une sélection de projets et une section compétences centrée sur l'intégration, React, le responsive, les interactions, les données/API et la qualité du code.

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion

## Lancer le projet

```bash
npm install
npm run dev
```

## Vérifier le build

```bash
npm run build
```
